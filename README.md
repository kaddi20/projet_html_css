-Présentation du projet :
Le projet est un site web pour une salle de sport appelé Élan Fitness.il permet de présenter la salle, les activités sportives et les différents programmes.

-Objectif du projet:
Créer un site web simple, moderne et facile à utiliser.

-Technologies utilisées:
HTML5
CSS3

-Fonctionnalités
Présentation de la salle de sport.
Affichage des activités et des programmes.
Formulaire de contact.
Effets hover sur les cartes et les images.
Design responsive pour les ordinateurs, les tablettes et les téléphones.

-Ressources et documentation
YouTube.
W3Schools
Mes camarades

-Conclusion
Ce projet m’a permis de pratiquer HTML et CSS et d’apprendre de nouvelles choses en développement web.
